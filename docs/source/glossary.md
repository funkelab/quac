# Glossary

```{glossary}
source image
  The image for which QuAC computes an explanation.

source class
  The class label of the source image.

target class
  The class requested from the generator.

generator
  A model that produces a generated image from a source image, conditioned on a target class and style.

generated image
  The output of the generator for a source image and target class.

attribution map
  A spatial array with values in [0,1] indicating which regions contribute to the difference between the source and generated images.

mask
  An array selecting regions of the generated image to blend into the source image. Binary masks are smoothed before blending.

mask area
  The fraction of pixels selected by a binary mask, measured before smoothing.

counterfactual
  An image formed by blending a source image and a generated image using a mask.

style
  A representation of class-dependent features, obtained from a reference image or a latent vector.

reference image
  An image of the target class from which a style is extracted.

latent vector
  A random Gaussian vector from which a style is generated by the mapping network.

delta
  The target-class probability of a counterfactual minus the target-class probability of its source image.

optimal delta
  The delta of the counterfactual whose mask maximizes delta divided by positive mask area.
```
